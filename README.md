# Cyber Shift — สำนักงานพิทักษ์ฝัน (0.8)

เกมฝึก Cyber Security ภาษาไทยในสำนักงานสามมิติแนวกึ่งนิทาน เล่นเป็นพนักงาน เดินไปหามะลิและอุปกรณ์ในสำนักงาน แล้วลงมือสืบสวนเหตุการณ์จำลอง รองรับ Mac, iPhone/iPad และเบราว์เซอร์ที่ใช้ WebGL ได้ ไม่มีเพลงหรือเสียงประกอบ

## วิธีเล่น

เริ่มเข้าเวรครั้งแรกจะฝึกสำรวจ 5 จุดก่อนเลือกคดี: ศูนย์เฝ้าระวัง SOC → โต๊ะตรวจระบบ → มะลิ → คอมมะลิ → Red / Blue Lab จุดสีทองบนพื้นพาไปยังจุดถัดไป ที่ SOC เปิดจอจริงและอ่านรายละเอียด Log ที่โต๊ะตรวจระบบลองใช้ไอเท็มจริงทั้ง 4 ชนิด คุยกับมะลิ แล้วเปิด Nara Mail อ่านเมลหนึ่งฉบับและพิมพ์ `whoami` เองใน Terminal Lab บน macOS, Windows และ Linux ปิดท้ายด้วยการอ่านคำขอใน Red / Blue Lab บทฝึกไม่เปลี่ยนคะแนนคดีและไม่ใช้ไอเท็ม เปิดฝึกซ้ำได้จาก พักเกม → วิธีเล่นและฝึกเดิน

- คลิกหรือแตะพื้นเพื่อเดิน บนคอมใช้ WASD/ลูกศร บนมือถือแตะป้ายจุดหมาย ปุ่ม “พาไปจุดฝึก” หรือ “พาฉันไปจุดภารกิจ” ช่วยนำทาง
- ที่คอมมะลิ เปิด Nara Work, เบราว์เซอร์ Google จำลอง และ Nara AI แบบบทสนทนาที่เตรียมไว้ ล็อกอินบัญชีฝึกด้วยข้อความใดก็ได้ รหัสผ่านไม่ถูกบันทึก
- เปิดอีเมลบริษัท 10–20 ฉบับต่อเหตุการณ์ โดยเริ่มเห็น 5 ฉบับ แล้วทยอยมาอีก 1 ฉบับทุก 9 วินาทีระหว่างเล่น ค้นหา อ่าน และแยกแยะอีเมลทั่วไป สแปม และฟิชชิ่ง เมลที่เปิดอ่านแล้วย้ายไปหมวด “อ่านแล้ว” ส่วนเมลใหม่อยู่หมวด “ยังไม่อ่าน” รายงานฟิชชิงหลังตรวจเบาะแสครบจะได้ +10 คะแนนโดยไม่ต้องเปิดลิงก์ล็อกอิน เนื้อหาเมลยาวขึ้น และผู้ส่งสอดคล้องกับเนื้อหา รายการสุ่มแบบคงที่ระหว่างเล่นคดีเดียวกัน
- หากเลือกดูตัวอย่างลิงก์ฟิชชิ่ง จะพบหน้าล็อกอินจำลองที่มีโดเมนคล้ายเว็บบริษัท และหน้าคำเตือนเข้มข้นที่แยกผลของการเปิดลิงก์ออกจากการกรอกรหัส อธิบายกลลวง วิธีจัดการทันที และวิธีป้องกันครั้งต่อไป
- ที่จอ SOC เฝ้า Log ที่ทยอยเข้ามา ค้น IP ชื่อผู้ใช้ ปลายทาง โปรโตคอลและพอร์ต แล้วเทียบหลักฐานก่อนตอบสนอง เวรแต่ละครั้งสุ่มบางเหตุการณ์ได้ทั้งเกิดและไม่เกิด ล็อกอินจากต่างประเทศอาจเป็นพนักงานเดินทางจริงหรือผู้บุกรุก ต้องตรวจอุปกรณ์และ MFA ก่อนอนุญาตหรือปฏิเสธ การลองรหัสผิดเริ่มจากครั้งเดียวแล้วเพิ่มเป็นหลายครั้งและหลายบัญชี ก่อนเลือกบล็อก
- เลือกเล่น 3 คดีในลำดับใดก็ได้: ฟิชชิ่งและเซสชันค้าง, ไฟล์ถูกล็อกและการกู้คืน, โปรแกรม DeskBuddy ที่ขอสิทธิ์เกินหน้าที่ แต่ละคดีบันทึกความคืบหน้าแยกกัน ภายในคดียังต้องเก็บหลักฐานและตอบสนองตามเหตุที่เกิด ดาวน์โหลดและกักไฟล์เป็นภาพจำลอง ไม่มีไฟล์จริงลงเครื่อง
- ในห้อง Red Team รับหรือปฏิเสธอีเมลลูกค้า กำหนดขอบเขตก่อนทดสอบพอร์ทัลของเล่นที่เตรียมไว้ เก็บหลักฐาน แก้ไข ทดสอบซ้ำ และเขียนรายงาน
- มีพลังใจ 5 ดวง การตัดสินใจผิดที่มีผลเสียลด 1 ดวง เมื่อหมดจะเห็นฉาก Game Over และเริ่มเวรใหม่ได้ กระเป๋าไอเท็มมีแว่นส่องเบาะแส ชุดกู้ใจ โล่กันภัย และเรดาร์สแกน เดินเข้าใกล้ไอเท็มที่เรืองแสงบนพื้นหรือแตะป้ายไอเท็มเพื่อเก็บเข้ากระเป๋า เก็บได้ชิ้นละครั้งต่อเวรและบันทึกไว้ในเซฟ แตะไอเท็มในกระเป๋าเพื่อดูผลและเงื่อนไขก่อนใช้ ป้ายบนจอแสดงเมื่อโล่พร้อมหรือสแกนเมลในคดีนี้แล้ว จบคดีครั้งแรกได้รับชุดกู้ใจเพิ่ม
- เมื่อจบแต่ละคดี เกมแสดงที่มาของคะแนน จุดที่ตอบผิดพร้อมเหตุผล และสรุปวิธีผ่านทุกขั้น เปิดดูย้อนหลังได้จากสมุดคดี สมุดคดียังส่งออกรายงานได้

## ติดตั้ง

Mac Apple Silicon / macOS 13+: แตก `Cyber-Shift-Mac.zip` แล้วเปิด `Cyber Shift.app` แอปบรรจุไฟล์เกมไว้ทั้งหมดและเล่นได้โดยไม่ต้องเปิดเซิร์ฟเวอร์ ลงนามแบบ ad-hoc แต่ยังไม่ได้ notarize ด้วย Apple Developer ID

iPhone/iPad: เปิดเว็บไซต์ใน Safari แล้วเลือก แชร์ → เพิ่มไปยังหน้าจอโฮม เปิดออนไลน์ครั้งแรกเพื่อแคชไฟล์ก่อนเล่นออฟไลน์ ความคืบหน้าอยู่ในอุปกรณ์แต่ละเครื่อง ไม่มีการซิงก์ และ iOS อาจล้างแคชเมื่อพื้นที่ไม่พอ

## ขอบเขตและซอร์ส

ชื่อบริษัท บัญชี โดเมน IP ข้อมูล SOC และการทดสอบ Red Team เป็นเรื่องสมมติทั้งหมด ไม่เชื่อม Google, AI จริง, เมลจริง หรือเป้าหมายภายนอก ไม่มีโค้ดโจมตีระบบจริง ทั้งสามคดีเป็นต้นแบบที่เล่นจบได้สำหรับเกมขนาดใหญ่ในอนาคต

`dist/` คือแอปเว็บแบบไม่ต้อง build; `dist/world.js` สร้างสำนักงานและพนักงานสามมิติ; `dist/game.js` จัดการภารกิจ; `dist/sim.js` สร้างข้อมูลคดี; `dist/workstation.js` และ `.css` สร้างหน้าจอคอมจำลอง; `mac/` คือ WKWebView wrapper; `tests/` ทดสอบกติกา ความคืบหน้า และข้อมูลจำลอง คำสั่งทดสอบ: `node --test tests/*.test.cjs`

เซฟแคมเปญ `cyber-shift-campaign-v1` อ่านและย้ายความคืบหน้าจาก `cyber-shift-office-v2` โดยไม่ลบเซฟเดิม; สถานะหน้าจอคอมใช้ `cyber-shift-workstations-v1` แยกต่างหาก Three.js 0.160.1 (MIT) และ Kanit (SIL OFL) บรรจุในแอปพร้อมไฟล์สัญญาอนุญาต

- หน้าเริ่มเปิดรอบฝึกสำรวจก่อน จากนั้นเปิดกระดานเลือกคดี โดยเลือกคดีใดก่อนก็ได้ โหมดสำรวจอิสระยังเข้าได้จากหน้าเริ่มหรือเมนูพัก เลือกเหตุอีเมลหลอก ไฟล์ถูกล็อก หรือแอปเสี่ยงจากโต๊ะกลาง แล้วเดินไปคอมพิวเตอร์, SOC หรือ Red Team ได้ทันที
- ศูนย์แอปมี Store จำลอง 3 แอป และเว็บไซต์จำลอง 2 แอป แอปปกติเปิดได้ ส่วนไฟล์เสี่ยงจากเว็บจะสร้างเหตุ SOC เฉพาะเมื่อผู้เล่นเลือกเปิดเอง ไม่มีการดาวน์โหลดไฟล์จริง
- Nara Guard บนคอมมะลิสแกนแอปที่ติดตั้ง หากเปิด DeskBuddy Pro โดยไม่สแกนหรือแยกเครื่อง SOC จะเห็นการติดต่อออกก่อน แล้วอาจยืนยันว่าเอกสารจำลองรั่วไหล การสแกนช้าหยุดกิจกรรมต่อได้ แต่ย้อนคืนข้อมูลที่รั่วไปแล้วไม่ได้
- ผู้ช่วยนกฮูกให้คำแนะนำสั้น ๆ หลังคลิกลิงก์และกรอกข้อมูลบนหน้าหลอก เปิดแอปเสี่ยง สแกนเครื่อง และตัดสินใจใน SOC; Nara Update จำลองการติดตั้งแพตช์จากตัวจัดการที่เชื่อถือได้ จอ SOC แสดงสัญญาณเตือนก่อนรูปแบบ brute force จะชัดเจน

### Terminal Lab และการตรวจใบรับรอง

ในคอมมะลิเปิด **Terminal Lab** เพื่อฝึก `whoami`, `hostname`, คำสั่งดู IP/พอร์ตของ macOS, Windows และ Linux และตัวเลือก Nmap ที่กำหนดไว้กับ IP ห้องแล็บ `192.0.2.10` เท่านั้น ทุกผลลัพธ์เป็นตัวอย่างในเกม ไม่มี shell หรือ network scan จริง หากพิมพ์เป้าหมายอื่นระบบจะอธิบายขอบเขตและไม่ทำงานต่อ

ในเบราว์เซอร์จำลองเลือก **ตรวจใบรับรองเว็บไซต์** เพื่อดู origin/protocol/secure context ของหน้าเกมจริงและเรียนวิธีเปิดตัวตรวจใบรับรองของเบราว์เซอร์ ตัวอย่างโดเมนฟิชชิงแยกป้ายว่าเป็นข้อมูลจำลองชัดเจน JavaScript ในหน้าเว็บไม่ได้อ่านผู้ออกและวันหมดอายุของ TLS certificate จึงต้องใช้ตัวตรวจของเบราว์เซอร์เพื่อดูข้อมูลนั้นจริง


### คำใบ้เมื่อค้างในคดี

ในโหมดคดี หากอยู่ขั้นเดิมต่อเนื่อง 60 วินาที เกมแสดงคำใบ้เบื้องต้นบนหน้าที่กำลังเล่นอยู่ หากยังไม่ผ่านขั้นนั้นถึง 120 วินาทีจะมีคำใบ้ที่ชัดขึ้น คำใบ้ไม่หักหัวใจและซ่อนได้; ตัวนับหยุดเมื่อพักเกมหรือปิดแท็บ และเริ่มใหม่เมื่อผ่านขั้นหรือเริ่มคดีใหม่ โหมดสำรวจอิสระไม่มีคำใบ้ตามขั้น

QR code สำหรับแชร์ลิงก์หลักของเกม: `Cyber-Shift-QR.png` ชี้ไปที่ `https://cyber-awareness-training-test0-1.pages.dev/`
